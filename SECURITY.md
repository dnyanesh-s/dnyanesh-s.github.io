# Security Policy

## Supported Versions

This project is a personal portfolio website. Only the latest version on the
`main` branch is actively maintained.

## Reporting a Vulnerability

Please report security vulnerabilities privately by emailing:

`dnyaneshwar1995@gmail.com`

Please include:

- A description of the issue
- Steps to reproduce it
- The potential impact
- Any suggested fix

Please do not disclose the issue publicly until it has been reviewed.

## Response

Valid reports will be acknowledged within 7 days, with updates provided as the
issue is investigated and resolved.
